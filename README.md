# Pakistan Agriculture & Livestock Analytics

A Power BI dashboard analyzing Pakistan's agricultural production, crop productivity, livestock population, livestock products, land utilization, and regional production patterns using multi-year data (2010-11 to 2025-26).

## 📊 Overview

- **Crop Categories:** 12
- **Livestock Categories:** 8
- **Regions Covered:** 5
- **Years of Data:** 16

The dashboard is built across 5 pages, moving from a high-level executive summary to a decision-support view that ties crop and livestock performance together.
